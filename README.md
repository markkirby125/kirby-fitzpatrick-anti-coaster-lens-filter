## Overview

The **kirby-fitzpatrick-anti-coaster-lens-filter** skill transforms cognitive writing science into deterministic rules for AI coding assistants, code reviews, and system documentation.

## Quick Installation & Universal Setup

Add this skill directly to your coding assistant by pasting the **Magic Prompt** below into your agent chat:


## Core Patterns

- **Anti Coaster Lens**: Anti-Coaster Filter: reject clever abstractions, unnecessary generics, and speculative patterns; enforce simple idiomatic code.
- **Practical Application**: Enforcing YAGNI and rejecting architectural over-engineering.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
